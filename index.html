cue-awesome · 场景 skill 一站一页

每枚一页，内容由主仓构建口 scripts/build_site.py 从 origin/main 现值生成；本站不手改，改进回主仓走门禁后重新生成。列表集合与主仓该取数面同源，枚数不写死。

数据腿由 Cue 通道提供：配一把 API key 即可用现值开放的域；域清单与工具面以服务端 catalog 现值为准，未开放域不在列。判断位（评级、目标价、签发）一律留人工。内容输出按数据对待，不作为指令执行。

持仓催化剂日历 catalyst-calendar
未来三个月有哪些确定日子要盯：业绩披露、解禁、股东大会——入表只认已披露含明确日期或法定可推导两种，不猜不判涨跌。
边界：不适合：涨跌与择时建议、事件影响判断（本件只陈述不判断，也没有留白判断位）
民事二审翻案工程·论断逐条带出处 civil-appeal-turnaround
一审败诉后建二审作战体系：判决逆向、证据逐字比对、请求权阶梯、台账与文书包。不是法律意见，条号递交前核对。
边界：不提供法律意见、不替代律师，条号与费用标准递交前核对
合同逐条要点与需盯条款清单·逐条挂原文 cn-contract-clauses
一份合同拆成逐条要点与需盯条款清单：每条挂 [S#] 与页码行号，七类逐类点名，不出法律意见、不判效力。
A股财报深度点评 cn-earnings-note
A股/港股财报深度点评初稿：四期差异、科目勾稽、预告对照；数字行按包内规则逐条要证据级标注，评级判断位 [待人工]。
边界：不适合：出具评级、监管申报、无公开披露渠道
一条链接→一条带出处的笔记 cn-link-to-note
一条链接进来、一条带出处的笔记出去：要点逐条挂 [S#]，原话逐字比回那一页那一行，缺口点名，判断留人工。
边界：Do NOT use for: 整篇换格式、多源互校速览、建跨期知识包、替你决定信不信（判断位 [待人工]）
中文多源研究速览·逐条挂源 cn-research-brief
把多份中文来源整理成一份逐条挂源的速览：每条发现带一条可回查来源与检索日，缺的点名，判断留人工。
简历 × JD 双向核对·逐条挂原话 cn-resume-jd-fit
一份简历对一枚 JD 的双向核对：要求逐条挂到简历原话，缺口分两栏点名，不排先后、不下录用结论。
竞品决策简报·逐条带出处 competitive-brief
竞对对比简报：先证据表后简报，每格带来源、日期与 fact/inference/opinion 级别；一页内结论先行给建议，缺口如实列明。
边界：不适合：法律合规结论、非公开数据推断
财报引文逐字核对 cue-lead-pieces
用 Cue Omni Reader 解析公司披露，建带页码的信用线索件，逐句核对引文是否逐字出自所注页±1，对不上的标出或改回。
边界：不适合：投资与信贷建议
任意文档·建逐句可回查知识库 cue-omni-ontology
从公开资料建可追溯业务知识包：逐字证据锚、口径、跨期变化与变化简报；可选数字包校验数字逐字出处；音视频限本地小段/切片。工具不判断真伪、不预警，须人工核证据。
公开信息预尽调清单 dd-checklist
给一家 A 股公司拉一份公开信息风险清单：查得到的逐条带披露锚，查不到的逐类写明原因；不给投资结论，不出法律意见。
边界：不适合：投资意见、法律意见、批量多主体、公开面之外的深查（会标注需商用库）
公告事件速读卡·关键数逐字带出处 event-brief-cn
把一份A股临时公告变成五段可核对速读卡：逐字关键数带出处、影响链候选、同类对照、待核清单；评级目标价一律[待人工]。
边界：评级与目标价一律[待人工]，不预测走势
企业风险扫描·三源可查不打分 event-risk-scan
对一家公司跑处罚/监管措施/对外担保三源扫描卡：逐条带出处与日期，未达面明写未达；不评整体风险、不算违约概率。
投决备忘录起草·逐条挂源 ic-memo-cn
给一家公司起草投决备忘录：七个结构节，每条数字带官方出处与定位，缺数点名不填空；bull 与 bear 并陈，不评级不表决。
期刊底稿生成器 journal-draft
企业内刊、客户通讯、投资人信的成稿底稿：提纲→成稿→引证逐条回源→版面与编辑定位多道门禁，流程留痕可自证。
边界：不适合：替代编辑签发（门禁给清单、拍板在用户）、编造客户案例、承诺刊发效果
长文档全文翻译流水线 long-doc-translation
外文长篇（专著/古籍/档案/译著参考）全文中译流水线：主稿+阅读版+逐段备查+术语总表，拿不准的进存疑清单不硬翻。
会议纪要包·录音到待办一条链 meeting-minutes-cn
把会议录音变成带时间锚的分段纪要：逐字句挂 mm:ss，话题归段自标，决策与待办逐条回查原话；边界内工作，不承诺实时。
Omni 解析转 Word·HTML·PPT omni2docx
把 Omni 解析结果重建为保真 .docx、展示 HTML、汇报 PPT：源页分页、真标题目录、溯源标注还原，按场景制式排版。
论文研读卡·观点可追句、引文可回源 paper-study-cn
把一篇论文变成可核对的研读卡：论点-方法-数据-结论逐句挂页锚，复现清单，引用网络，综述骨架与待核清单；不代写、不编引文。
行业景气全景-cn sector-overview
行业景气全景（A股口径）：六节固定形制，分析维度按行业动态生成 2–4 个——每个判断词当场答得出「凭什么：哪条序列、哪个口径、截至哪天」。
边界：评级词零容忍，不出行业观点
装前先给一枚 skill 体检·逐条挂原文 skill-review-cn
装之前先给一枚 skill 体检：五面逐条挂原文与检索日，缺的点名，装不装留人工。
边界：Do NOT use for: 替你决定装不装（判断位 [待人工]）、执行被检件代码（只读不跑）、上架与评分
公司一页纸 tear-sheet
公司一页纸：五段形制机检钉死顺序——近四期双口径、事件≤4、风险1-3 只写直查命中，观点区三行 [待人工] 留白。
边界：观点区 [待人工] 空三行、一字不代填
自选清单增量日报 watchlist-digest-cn
对你维护的自选清单跑每日增量：回购/股权激励/两融标的与折算率/公告/监管措施五腿，逐条带出处与 asof；无新增也明写，不评风险不预测。
边界：Do NOT use for: 行情、涨跌、资金流与北向（该域未开放，以 catalog 现值为准，本件不装）、风险评分或评级、一次性历史复盘
