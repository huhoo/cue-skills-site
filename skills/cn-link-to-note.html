一条链接→一条带出处的笔记

cn-link-to-note · 场景 skill · 全部列表见 index

这枚做什么

一条链接进来、一条带出处的笔记出去：要点逐条挂 [S#]，原话逐字比回那一页那一行，缺口点名，判断留人工。

能力与边界（原文完整描述）

链接→笔记起草：输入是一枚 URL（正文走解析通道取回本地那一份）或一份本地文件，产出是一条可直接进笔记库的 Markdown 笔记——标题、要点 3–7 条（每条一个 [S#] 锚）、至多一枚原话引用（逐字，带页码或行号）、口径与未取到、来源行（带 文件:行号 或 URL 与检索日）。机检 check_note.py 四道：形制／锚与定位／引用是否逐字回原文／缺口是否点名，零网络。适合读完一篇先落一条能回查的笔记。Do NOT use for: 整篇换格式、多源互校速览、建跨期知识包、替你决定信不信（判断位 [待人工]）。Triggers: 链接转笔记 / 一条笔记 / 带出处笔记

边界句

Do NOT use for: 整篇换格式、多源互校速览、建跨期知识包、替你决定信不信（判断位 [待人工]）

安装

npx skills add huhoo/cue-awesome --skill cn-link-to-note

该行取自该枚包内面文（README.md）原句，非本页撰写；版本与变更以该枚 frontmatter 与该枚 CHANGELOG 现值为准。

示例输出

# 样本量不到三十时，比例别写成趋势（一条笔记）

本页由 AI 整理，是 **AI 整理笔记**：每条要点都请回原文核对，它不构成结论或建议，判断位 [待人工]。
链接：https://example.org/sample-note ｜检索日 2026-10-22｜读取方式：解析通道把正文取回成本地那一份后只读它
这条笔记的形状：要点各一行、行末挂 [S#]；原话只留一句、带页码；缺的那部分写在第三节点名。

## 1、要点

- 结论位：一项调研的样本量不到三十时，其比例不宜对外表述为趋势——这是作者在第一段自己下的那句 [S1]
- 方法：访谈分三轮、每轮换人，同一轮的答复不被当作复证 [S1]
- 限制：文中的百分比全部来自有偏样本，作者明写不能外推到全行业 [S1]
- 附录一有问卷原题十一道，其中三道是开放题 [S2]
- 访谈提纲与实问之间存在偏差，而那份材料没给偏差率的数 [S2]

## 2、原话引用

> 「一项调研的样本量如果不到三十，其比例不宜对外表述为趋势。」（出处：〔第 1 页〕，https://github.com/huhoo/cue-awesome/blob/main/cn-link-to-note/scripts/fixtures/source-article.md:5）

## 3、口径与未取到

- 口径：五条要点全部出自同一份正文，本件不做跨源互校——单源笔记不做互校是设计，不是遗漏
- 未取到：作者署名与发布日期在取回的那份正文里没有（页眉页脚都无），本笔记不代填
- 口径：检索日 2026-10-22；链接那一侧隔天就可能换形制，页码与行号只在那一刻成立
- 判断位：这条笔记要不要进你的库、信不信这句结论，一律 [待人工]
