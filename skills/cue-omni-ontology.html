任意文档·建逐句可回查知识库

cue-omni-ontology · v0.3.11 · MIT · 来源 仓库子目录

从公开资料建可追溯业务知识包：逐字证据锚、口径、跨期变化与变化简报；可选数字包校验数字逐字出处；音视频限本地小段/切片。工具不判断真伪、不预警，须人工核证据。

安装

npx skills add huhoo/cue-awesome --skill cue-omni-ontology

或：从 Releases 下载 cue-omni-ontology.zip 解到宿主 skills 目录（每枚同名资产在最新一发）。

完整说明

从用户指定的公开文档建可追溯业务知识包：宿主模型抽取实体、口径与断言，工具把逐字摘录绑定为字节级证据（可带入 Omni 原生页码），并执行打包、更新、跨期变化/冲突列表、查询与变化简报；可选数字包只校验宿主算出的数字与来源页逐字一致。工具不判断事实真伪、不做预警或风险发现，结论须人工核对证据。适合：披露跟踪、供应商/产品变化、口径核对、业绩会音视频（本地小段/切片≤256 MiB）。Triggers: ontology extraction, disclosure tracking, evidence briefs, numeric pack, 知识包， 变化简报。

本仓库的 skill 不判断真伪、不做预警；评级与目标价一律留人工。数据腿由 Cue 通道提供，配一把 API key 即可，无需自备数据源或自建数据层。
