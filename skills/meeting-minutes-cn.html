会议纪要包·录音到待办一条链

meeting-minutes-cn · v0.2.28 · MIT · 来源 仓库子目录

把会议录音变成带时间锚的分段纪要：逐字句挂 mm:ss，话题归段自标，决策与待办逐条回查原话；边界内工作，不承诺实时。

安装

npx skills add huhoo/cue-awesome --skill meeting-minutes-cn

或：从 Releases 下载 meeting-minutes-cn.zip 解到宿主 skills 目录（每枚同名资产在最新一发）。

完整说明

企业会议纪要：给我会议录音（本地文件，以通道返回为准）与可选材料，产出五段纪要——基本信息、逐字带时间锚、话题分段（归类是笔记法非原文）、决策与待办每条挂原话锚、待核清单。Do NOT use for: 实时转写、单件超 256 MiB 的整场录音直投（闸按字节不按时长；单件 ≤256MiB 为已实证边界）、替你把纪要改写成「更漂亮」的版本。适合「这段录音整理成纪要」「会是哪几件事谁负责」「纪要逐条对回原话」等场景。Triggers: 会议纪要 / 录音整理 / 谁负责什么 / 待办提取 / 逐字回查； meeting minutes / audio to notes

本仓库的 skill 不判断真伪、不做预警；评级与目标价一律留人工。数据腿由 Cue 通道提供，配一把 API key 即可，无需自备数据源或自建数据层。
