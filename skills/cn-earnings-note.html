A股财报深度点评

cn-earnings-note · v0.3.43 · MIT · 来源 仓库子目录

A股/港股财报深度点评初稿：四期差异、科目勾稽、预告对照；数字行按包内规则逐条要证据级标注，评级判断位 [待人工]。

安装

npx skills add huhoo/cue-awesome --skill cn-earnings-note

或：从 Releases 下载 cn-earnings-note.zip 解到宿主 skills 目录（每枚同名资产在最新一发）。

完整说明

给你一家公司 + 报告期，产出八节点评初稿：四期差异、科目勾稽、指引与兑现对照、盈利质量分桶、预测脚手架。适合：财报复盘、投研底稿、晨会；不适合：出具评级、监管申报、无公开披露渠道。四道机检的如实范围：①AI 声明与 [待人工] 就位；②散文数字行须有证据级标注，逐条拦+95%（哪些行算「数字行」以包内 check_note.py 两条正则现值为准，本文举例非穷尽；列表行与索引节按设计豁免）；③账本数值对象带basis字段；④合规词表最小集。--sources 仅给出时校验 JSONL 形制与自写 [S] 可解析，不逐条要求带锚、不回查原文；「同比/单季」属出稿纪律，靠人守。

本仓库的 skill 不判断真伪、不做预警；评级与目标价一律留人工。数据腿由 Cue 通道提供，配一把 API key 即可，无需自备数据源或自建数据层。
