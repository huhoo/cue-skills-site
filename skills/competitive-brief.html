竞品决策简报·逐条带出处

competitive-brief · v0.3.31 · MIT · 来源 仓库子目录

竞对对比简报：先证据表后简报，每格带来源、日期与 fact/inference/opinion 级别；一页内结论先行给建议，缺口如实列明。

安装

npx skills add huhoo/cue-awesome --skill competitive-brief

或：从 Releases 下载 competitive-brief.zip 解到宿主 skills 目录（每枚同名资产在最新一发）。

完整说明

给你主体 + 竞品清单，产出简报：结论先行（一页以内、含可执行建议），对比表每格对应证据表单元格——fact 直接可证 / inference 由多事实推导 / opinion 无可引用来源就标 opinion、置信度宁可空着不填「高」。流程硬规矩：证据表没填的维度不写进简报；结论性主张必须先进表；简报末尾列行数、置信度分布与完全没覆盖的维度。适合：尽调背景、会前准备、策略讨论。不适合：法律合规结论、非公开数据推断。 Do NOT use for: legal conclusions, non-public inference, guesses as sources.

本仓库的 skill 不判断真伪、不做预警；评级与目标价一律留人工。数据腿由 Cue 通道提供，配一把 API key 即可，无需自备数据源或自建数据层。
