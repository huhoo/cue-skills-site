持仓催化剂日历

catalyst-calendar · v0.1.30 · MIT · 来源 仓库子目录

未来三个月有哪些确定日子要盯：业绩披露、解禁、股东大会——入表只认已披露含明确日期或法定可推导两种，不猜不判涨跌。

安装

npx skills add huhoo/cue-awesome --skill catalyst-calendar

或：从 Releases 下载 catalyst-calendar.zip 解到宿主 skills 目录（每枚同名资产在最新一发）。

完整说明

给你持仓列表 + 时间窗，产出按日期排的盯盘日历：每条事件的日期要么已有披露在场且含明确 YYYY-MM-DD，要么 statute 原文推导且适用条件在锚内可判；未披露的推测事件、任何日期算术都进不了表。机检对评级词与褒贬零容忍（词族以机检现值为准，本文所举为常见例）。适合：财报季前置、组合盯盘节奏、投研会材料。不适合：涨跌与择时建议、事件影响判断（本件只陈述不判断，也没有留白判断位）。豁免只有两条口径：类型列整列不扫、官方披露词组按词形豁免。 Do NOT use for: trade timing, impact calls, rumour-sourced events.

本仓库的 skill 不判断真伪、不做预警；评级与目标价一律留人工。数据腿由 Cue 通道提供，配一把 API key 即可，无需自备数据源或自建数据层。
