这枚做什么

外文长篇（专著/古籍/档案/译著参考）全文中译流水线：主稿+阅读版+逐段备查+术语总表，拿不准的进存疑清单不硬翻。

能力与边界（原文完整描述）

外文长文（德/英/法/日，授权可访问）产出四类交付：主稿 .md、自包含阅读版 .html、逐段备查、新术语总表；存疑交人工不强译。 Do NOT use for: publishing copyrighted text as-is, practice-grade legal output.

安装

npx skills add huhoo/cue-awesome --skill long-doc-translation

该行取自该枚包内面文（README.md）原句，非本页撰写；版本与变更以该枚 frontmatter 与该枚 CHANGELOG 现值为准。

示例输出

# 产物形态样例：一部合成三篇稿合完的「译著主稿.md」

**这枚文件是什么**：本包四步链（`overlap_check.py` → `qa_check.py` → `dedup_boundary.py` → `merge_build.py`）跑包内好样夹具 `scripts/fixtures/good/` 三片后，`merge_build.py` 落盘的那份主稿原样，一行没改、一字没补——给还没用过的读者看「交回来的东西长什么样」：篇标题、原书页码单独成行、正文、各片脚注、书末新术语总表。
**里面的人物、机构、书名、页码全是合成的**（那部"德文书"与 001/002/003 片都是虚构样件）；本页不含任何真实个人、机构或文件。
**自证整条链（一条命令）**：`python3 -B https://github.com/huhoo/cue-awesome/blob/main/long-doc-translation/scripts/check_translation.py --selftest`（零网络、纯标准库；一档就是把这三片走完整条链再逐项断言）。它验的是形制，临时根跑完即删——**这份主稿本体它不留在盘上**，所以下面这四条才是拿到这个文件的走法。
**复跑这份文件本体（四步链，连取根、断言与铺夹具共七行；临时根用 `mktemp -d` 现取一枚唯一名，同机多会话也不互撞，取不到就当场停手，跑完自己删）**：

```bash
RUN="$(mktemp -d "${TMPDIR:-/tmp}/long-doc-translation-sample-XXXXXX")" || { echo "取不到临时根，停手"; exit 1; }
test -n "$RUN" && test -d "$RUN" || { echo "临时根空或不在，停手"; exit 1; }
cp -r scripts/fixtures/good "$RUN/good"
python3 -B https://github.com/huhoo/cue-awesome/blob/main/long-doc-translation/scripts/overlap_check.py "$RUN/good"
python3 -B https://github.com/huhoo/cue-awesome/blob/main/long-doc-translation/scripts/qa_check.py "$RUN/good" --expect 3

取自该枚包内样例件 scripts/fixtures/good_merged_sample.md——机检守护样例，不是用户产物、也不是某次运行结果。
