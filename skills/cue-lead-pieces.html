cue-lead-pieces · 场景 skill · 全部列表见 index

这枚做什么

用 Cue Omni Reader 解析公司披露，建带页码的信用线索件，逐句核对引文是否逐字出自所注页±1，对不上的标出或改回。

能力与边界（原文完整描述）

Agent 思考，Cue 感知：用 Cue Omni Reader 把公司自己的披露（A股巨潮/美股SEC EDGAR）解析成带原PDF页码的原文，产出信用线索件，并逐句核对答案引文是否逐字出自所注页±1；--fix 改正页码、换回原句、删掉原文没有的。可选 Cue data-MCP 列公告、cue-research 补背景；未开通 Cue 本地解析兜底。实测（本地解析、单一模型与宿主、24家）：裸Agent引文39%对不上，本件流程95%逐字可查。不适合：投资与信贷建议。Triggers: credit signals, quote verification, 10-K, 年报、引文核对。

# 产物形态样例：`brief` 一次给全的那张简报（合成主体）

**这枚文件是什么**：下面分隔线之后那 17 行，是本包 `cue.py brief` 那一条命令的 stdout 原样——材料目录（来源编号｜类型｜日期｜页数｜解析通道｜标题）＋线索件（对象·为何现在·建议动作）＋每条可直接粘贴的逐字证据（JSON 行），一行没改、一字没补。
**里面的主体、公告、页码与数字全是合成的**：出自本包已提交的合成夹具 `https://github.com/huhoo/cue-awesome/blob/main/cue-lead-pieces/scripts/fixtures/omni_real_shape.json`（@cueai/omni-reader-mcp 的实测回执形制、文本为合成、编号为假），本页不含任何真实机构、个人或真披露。
**怎么复跑**（纯标准库；临时根用 `mktemp -d` 现取一枚唯一名，同机多会话也不互撞，**取不到就当场停手、不带空路径往下跑**，跑完自己删）：

```bash
RUN="$(mktemp -d "${TMPDIR:-/tmp}/cue-lead-pieces-sample-XXXXXX")" || { echo "取不到临时根，停手"; exit 1; }
test -n "$RUN" && test -d "$RUN" || { echo "临时根空或不在，停手"; exit 1; }
export RUN
python3 -B - <<'PY'
import json, os, pathlib
fx = json.loads(pathlib.Path('https://github.com/huhoo/cue-awesome/blob/main/cue-lead-pieces/scripts/fixtures/omni_real_shape.json').read_text(encoding='utf-8'))
run = pathlib.Path(os.environ['RUN']); run.mkdir(parents=True, exist_ok=True)
