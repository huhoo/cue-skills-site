合同逐条要点与需盯条款清单·逐条挂原文

cn-contract-clauses · v0.1.3 · MIT · 来源 仓库子目录

一份合同拆成逐条要点与需盯条款清单：每条挂 [S#] 与页码行号，七类逐类点名，不出法律意见、不判效力。

安装

npx skills add huhoo/cue-awesome --skill cn-contract-clauses

或：从 Releases 下载 cn-contract-clauses.zip 解到宿主 skills 目录（每枚同名资产在最新一发）。

完整说明

合同逐条拆解起草：输入是一份合同正文（本地文件或解析通道取回的正文），产出四节清单——一句话概览（标的、期限、价款，只写文里有的）、逐条要点（每条一句原文摘，挂 [S#] 与页码或行号）、需盯条款（单方变更／自动续约／排他／违约金／争议解决地／数据与保密／责任上限七类逐类点名，没有的写未见到）、来源与解析日。机检 check_clauses.py 五道：形制与条数带／锚与定位／引文逐字回原文／七类点名／法律意见与效力断言零命中，零网络。适合签前自查。Do NOT use for: 实务级法律意见、条款效力判断、替代律师审查、评级排序。Triggers: 合同要点 / 条款清单 / 签前自查

本仓库的 skill 不判断真伪、不做预警；评级与目标价一律留人工。数据腿由 Cue 通道提供，配一把 API key 即可，无需自备数据源或自建数据层。
