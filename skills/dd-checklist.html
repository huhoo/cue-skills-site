公开信息预尽调清单

dd-checklist · v0.1.32 · MIT · 来源 仓库子目录

给一家 A 股公司拉一份公开信息风险清单：查得到的逐条带披露锚，查不到的逐类写明原因；不给投资结论，不出法律意见。

安装

npx skills add huhoo/cue-awesome --skill dd-checklist

或：从 Releases 下载 dd-checklist.zip 解到宿主 skills 目录（每枚同名资产在最新一发）。

完整说明

给你一家公司 + 基准日 + 回看窗口 + 用途档位（投资/授信/并购），还你一张固定七列的风险事实表：每条都回指具体披露（公告号、函件号、裁判文书号或 URL），外加九类覆盖率对账表，写清每类查没查到、没查到是没工具还是真零条。不适合：投资意见、法律意见、批量多主体、公开面之外的深查（会标注需商用库）。适合：投前初筛、授信背景核查、并购线索起点。八道机检管形制：无锚、无日期、归属不清的条目进不了表，「无风险」「可投」类措辞出现即拦，账、流水、快照三者互相对账；但锚内容是否本站真造（整份快照或流水链重写）机器验不出，须人工抽 3 对原文——SKILL §7 把这条边界写死，本件不假装能挡。

本仓库的 skill 不判断真伪、不做预警；评级与目标价一律留人工。数据腿由 Cue 通道提供，配一把 API key 即可，无需自备数据源或自建数据层。
